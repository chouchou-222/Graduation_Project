## 📝 配置文件参数详解

### 训练配置 (`GeoSeg/config/vaihingen/sffnet.py`)

```python
# ===== 数据相关 =====
train_batch_size = 2        # 训练 batch 大小
                            # 更小：模型更新频繁，但噪声大
                            # 更大：更稳定，但需要更多显存

val_batch_size = 2          # 验证 batch 大小
                            # 通常=(train_batch_size)或更大

num_classes = len(CLASSES)  # 分类数
                            # Vaihingen: 6 类
                            # LoveDA: 7 类

# ===== 学习率和优化 =====
lr = 6e-4                   # 主网络学习率
backbone_lr = 6e-5          # 骨干网络学习率
                            # 骨干通常用预训练权重
                            # 所以需要更小的学习率

weight_decay = 0.01         # L2 正则化强度
                            # 防止过拟合

accumulate_n = 1            # 梯度累积步数
                            # 模拟更大的 batch_size
                            # (不会增加显存使用) ⭐

# ===== 训练参数 =====
max_epoch = 105             # 总训练轮数
                            # 越多越好，但收益递减

check_val_every_n_epoch = 1 # 每 N 个 epoch 验证一次
                            # 1: 每个 epoch 验证（默认）
                            # 5: 每 5 个 epoch 验证一次（快速）

# ===== 模型恢复 =====
pretrained_ckpt_path = None # 预训练权重路径（通常不用）
resume_ckpt_path = None     # 恢复检查点
                            # 如果训练中断，设置上次的 ckpt 路径
                            # 例: "model_weights/vaihingen/sffnet-...-epoch=50.ckpt"

# ===== 检查点保存 =====
save_top_k = 3              # 保存最好的 K 个模型
                            # 3: 保存 mIoU 最好的 3 个

save_last = True            # 是否保存最后一个 epoch
                            # True: 总是保存，便于恢复训练

monitor = 'val_F1'          # 监控的指标
                            # 'val_F1': 监控 F1 分数
                            # 'val_mIoU': 监控 mIoU
                            # 选择哪个，就按哪个指标保存最好模型

monitor_mode = 'max'        # 监控模式
                            # 'max': mIoU 越大越好 ✓
                            # 'min': 损失越小越好

# ===== 硬件 =====
gpus = [0]                  # 使用的 GPU 编号
                            # [0]: 使用第一块 GPU
                            # [0, 1]: 使用第一和第二块 GPU
                            # []: 使用 CPU

strategy = None             # 分布式训练策略
                            # None: 单 GPU
                            # 'ddp': 多 GPU 数据并行
```

## 🔄 超参数调整指南

### 当模型收敛速度慢时

```python
# 增加学习率（但会变得更不稳定）
lr = 6e-4 → 1e-3            # ⬆️ 提高

# 增加 batch_size（需要更多显存）
train_batch_size = 2 → 4    # ⬆️ 提高

# 使用梯度累积代替
accumulate_n = 1 → 2        # ⬆️ 提高
# 效果：梯度累积 2 次再更新 = 模拟 batch_size=4（显存使用不变）

# 增加期轮数
max_epoch = 105 → 150       # ⬆️ 提高
```

### 当模型过拟合时（训练准确，测试差）

```python
# 增加正则化强度
weight_decay = 0.01 → 0.05  # ⬆️ 提高

# 增加 dropout
dropout = 0.1 → 0.3         # ⬆️ 提高

# 增加数据增强强度
mosaic_ratio = 0.25 → 0.5   # ⬆️ 提高

# 早停
check_val_every_n_epoch = 1 # 如果 val_loss 停止改进就停止
```

### 当显存不足时

```python
# 减小 batch_size
train_batch_size = 2 → 1    # ⬇️ 降低

# 优先考虑梯度累积
accumulate_n = 1 → 3        # ⬆️ 提高
# 如：batch_size=1, accumulate_n=3 = 等效 batch_size=3（显存只用1/3）

# 输入分辨率缩小（修改代码）
# 512 → 256  # 显存使用降至 1/4

# 使用混合精度训练（修改训练脚本）
# 将 float32 改为 float16
```

## 📊 监控指标参考表

### 训练过程中应该看到的

| Epoch | Train Loss | Val Loss | Val mIoU | 说明 |
|-------|-----------|----------|---------|------|
| 0 | ~0.8 | ~0.8 | ~0.05 | 模型随机初始化 |
| 10 | ~0.4 | ~0.5 | ~0.40 | 开始学到东西 |
| 30 | ~0.2 | ~0.3 | ~0.65 | 进步明显 |
| 60 | ~0.1 | ~0.25 | ~0.75 | 接近收敛 |
| 105 | ~0.05 | ~0.23 | ~0.80 | 基本收敛 |

**正常迹象** ✓：
- Train Loss 持续下降
- Val mIoU 持续上升
- 两者都比较平稳（无大波动）

**异常迹象** ⚠️：
- Loss 为 NaN（数据问题或学习率太高）
- Train Loss 下降，Val mIoU 却上升（过拟合）
- Train Loss 一直不动（学习率太小或模型未收敛）
- Loss 急剧增加（梯度爆炸）

### 自定义数据集加载

```python
from torch.utils.data import Dataset, DataLoader
import numpy as np
from PIL import Image

class CustomDataset(Dataset):
    def __init__(self, image_dir, label_dir):
        self.images = sorted(os.listdir(image_dir))
        self.labels = sorted(os.listdir(label_dir))
    
    def __len__(self):
        return len(self.images)
    
    def __getitem__(self, idx):
        img = Image.open(f'{image_dir}/{self.images[idx]}')
        label = Image.open(f'{label_dir}/{self.labels[idx]}')
        
        # 转为 tensor
        img = torch.from_numpy(np.array(img)).permute(2, 0, 1).float() / 255.0
        label = torch.from_numpy(np.array(label)).long()
        
        return img, label
```

## 🚨 常见错误速查

| 错误信息 | 原因 | 解决方案 |
|---------|------|---------|
| `CUDA out of memory` | 显存不足 | 减小 batch_size 或 input_size |
| `ModuleNotFoundError` | 库未安装 | `pip install [library_name]` |
| `FileNotFoundError` | 路径错误 | 检查数据路径和配置文件 |
| `RuntimeError: Expected 3D input` | 输入维度错误 | 检查数据形状 (B, C, H, W) |
| `Loss is NaN` | 数据故障或学习率过高 | 降低 lr，检查数据 |
| `CUDA is not available` | 没有安装 GPU 版本 PyTorch | 重新安装 torch==1.12.1+cu113 |
