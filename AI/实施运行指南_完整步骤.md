### 步骤 3.1：测试数据加载

创建 `test_dataloader.py`：

from GeoSeg.geoseg.datasets.vaihingen_dataset import VaihingenDataset
from torch.utils.data import DataLoader

# 创建数据集对象
dataset = VaihingenDataset(
    data_root='data/vaihingen/train',
    mode='train',
    mosaic_ratio=0.25,
    transform=None  # 暂不使用数据增强
)

print(f"数据集大小: {len(dataset)} 张图像")

# 查看单个样本
image, label = dataset[0]
print(f"单个图像形状: {image.shape}")  # 应该是 (3, 512, 512) 或类似
print(f"单个标签形状: {label.shape}")  # 应该是 (512, 512)
print(f"标签类别范围: {label.min()} 到 {label.max()}")

# 创建 DataLoader
dataloader = DataLoader(
    dataset,
    batch_size=2,
  num_workers=2,  # Ubuntu 上推荐先用 2，再按机器性能调到 4

# 获取一个 batch
for images, labels in dataloader:
    print(f"\nBatch 图像形状: {images.shape}")  # (2, 3, 512, 512)
    print(f"Batch 标签形状: {labels.shape}")    # (2, 512, 512)

## 📊 第七阶段：理解输出指标

评估脚本会输出：

```
Model Performance on Vaihingen Test Set
=====================================
Overall Accuracy: 0.8523
Mean Accuracy: 0.7245
Mean IoU: 0.6782

Per-class IoU:
  Class 0 (背景/杂物): 0.7234
  Class 1 (建筑):     0.8234
  Class 2 (道路):     0.6123
  Class 3 (树木):     0.5432
  Class 4 (低植被):   0.4234
  Class 5 (水):       0.8934
```

**指标解释**：

1. **Overall Accuracy** (客观正确率) = 正确像素数 / 总像素数
2. **Mean Accuracy** (平均正确率) = 各类别正确率的平均值
3. **Mean IoU** (平均交并比) = **最重要！** 各类别 IoU 的平均值
   - 范围 [0, 1]，越接近1越好
   - > 0.5：还可以
   - > 0.7：很好
   - > 0.85：优秀

## 🔧 常见问题调试

### 问题 1：显存不足 (CUDA out of memory)

```
RuntimeError: CUDA out of memory. Tried to allocate 2.00 GiB on cuda:0
```

**解决**：
1. 减小 batch_size：`train_batch_size = 1`
2. 减小输入分辨率：512 → 256
3. 减少梯度累积

### 问题 2：训练很慢

**可能原因**：
- 使用了 CPU 而不是 GPU
  ```bash
  # 检查
  python -c "import torch; print(torch.cuda.is_available())"
  ```
- num_workers 设置过大：Ubuntu 建议先设为 2，再尝试 4

### 问题 3：损失函数为 NaN

```
Loss is NaN!
```

**解决**：
1. 检查数据是否正确加载（没有 NaN 值）
2. 降低学习率 `lr = 6e-4 → 1e-5`
3. 检查数据归一化是否正确

### 问题 4：迭代速度不稳定

**可能原因**：
- 输入数据大小不统一
- num_workers 过多导致内存竞争

**解决**：
- 检查数据预处理
- 减少 num_workers
