### 基础构建块 (Building Blocks)

#### 1. ConvBNReLU 模块
```python
class ConvBNReLU(nn.Sequential):
    """
    三层融合：卷积 → 批归一化 → 激活函数
    
    工作流程：
    输入 ──→ [卷积] ──→ [批归一化] ──→ [ReLU激活] ──→ 输出
    
    参数说明：
    - in_channels: 输入通道数（如3：RGB，或64：特征）
    - out_channels: 输出通道数（通常和输入相同或加倍）
    - kernel_size: 卷积核大小（默认3×3）
    - dilation: 膨胀/孔洞卷积（用于扩大感受野）
    - stride: 步长（1=不缩放，2=减半）
    """
    def __init__(self, in_channels, out_channels, kernel_size=3, 
                 dilation=1, stride=1, norm_layer=nn.BatchNorm2d, bias=False):
        super(ConvBNReLU, self).__init__(
            # 卷积层
            nn.Conv2d(in_channels, out_channels, kernel_size=kernel_size, 
                      bias=bias, dilation=dilation, stride=stride,
                      # 自动计算 padding 保持分辨率
                      padding=((stride - 1) + dilation * (kernel_size - 1)) // 2),
            # 批归一化：标准化每个通道的值
            norm_layer(out_channels),
            # ReLU6 激活：max(x, 0)，用于移动端模型优化
            nn.ReLU6()
        )
```

**图解理解**：
```
输入特征图 (B × 64 × H × W)
      ↓
  Conv 3×3
    (64 → 128)
      ↓
特征图 (B × 128 × H × W)
      ↓
BatchNorm2d
  (标准化)
      ↓
ReLU6
  (激活)
      ↓
输出 (B × 128 × H × W)
```

#### 3. WF 模块（加权融合）
```python
class WF(nn.Module):
    """
    加权融合两个特征
    
    原理：
    不是简单的相加，而是学习一个权重
    
    输出 = w1 × 特征1 + w2 × 特征2
    
    其中 w1, w2 是可学习的参数（会在训练中自动调整）
    
    这样做的好处：
    - 模型可以自己决定什么时候用哪个特征
    - 不同场景下的融合比例会自动调整
    """
    def __init__(self, in_channels=128, decode_channels=128, eps=1e-8):
        super(WF, self).__init__()
        self.pre_conv = Conv(in_channels, decode_channels, kernel_size=1)
        # 两个学习的权重参数
        self.weights = nn.Parameter(torch.ones(2, dtype=torch.float32), 
                                   requires_grad=True)
        self.eps = eps  # 防止除以0的小数
        self.post_conv = ConvBNReLU(decode_channels, decode_channels, kernel_size=3)
    
    def forward(self, x, res):
        # 确保权重非负
        weights = nn.ReLU()(self.weights)  # [w1, w2]
        
        # 权重归一化（和为1）
        fuse_weights = weights / (torch.sum(weights, dim=0) + self.eps)
        # fuse_weights = [w1/(w1+w2), w2/(w1+w2)]
        
        # 加权融合
        x = fuse_weights[0] * self.pre_conv(res) + fuse_weights[1] * x
        
        # 经过卷积进一步处理
        x = self.post_conv(x)
        return x
```

### 主网络类 SFFNet

```python
class SFFNet(nn.Module):
    """
    完整的SFFNet网络
    
    架构流程：
    输入图像
       ↓
    [骨干网络提取多尺度特征]
       ↓
    [特征映射阶段 - 多尺度融合]
       ↓
    [小波变换 - 频率分解]
       ↓
    [MDAF - 空间频率融合]
       ↓
    [解码 - 上采样恢复分辨率]
       ↓
    分割结果（每像素的类别）
    """
    
    def __init__(self,
                 decode_channels=96,      # 内部特征通道数
                 dropout=0.1,             # 防过拟合的drop rate
                 backbone_name="convnext_tiny.in12k_ft_in1k_384",  # 骨干网络名称
                 pretrained=True,         # 是否用预训练权重
                 window_size=8,           # 注意力窗口大小
                 num_classes=6,           # 分类数（Vaihingen数据集6类）
                 use_aux_loss=True        # 是否使用辅助损失
                 ):
        super().__init__()
        self.use_aux_loss = use_aux_loss
        
        # ===== 第一部分：骨干网络 =====
        # timm 是预训练模型库，可以便捷地加载各种骨干网络
        # features_only=True: 只返回特征图，不返回分类head
        # output_stride=32: 最后输出的分辨率是输入的1/32
        # out_indices=(0, 1, 2, 3): 返回四个尺度的特征图
        self.backbone = timm.create_model(
            model_name=backbone_name,
            features_only=True,
            pretrained=pretrained,
            output_stride=32,
            out_indices=(0, 1, 2, 3)  # 返回4个多尺度特征
        )
        
        # 以 ConvNeXt 为例，输出的通道数是 [96, 192, 384, 768]
        # 我们需要统一转换为 decode_channels (通常96)
        
        # ===== 第二部分：通道转换 =====
        # 把不同尺度的特征转换为相同通道数
        self.conv2 = ConvBN(192, decode_channels, kernel_size=1)  # 96通道
        self.conv3 = ConvBN(384, decode_channels, kernel_size=1)  # 96通道
        self.conv4 = ConvBN(768, decode_channels, kernel_size=1)  # 96通道
        
        # ===== 第三部分：MDAF 多尺度对齐模块 =====
        # 用两个 MDAF 分别处理低频(L)和高频(H)特征
        self.MDAF_L = MDAF(decode_channels, num_heads=8, 
                          LayerNorm_type='WithBias')
        self.MDAF_H = MDAF(decode_channels, num_heads=8, 
                          LayerNorm_type='WithBias')
        
        # ===== 第四部分：特征融合 =====
        # FMS: 特征映射阶段，包含小波变换功能
        self.fuseFeature = FMS(in_ch=3*decode_channels,    # 输入:3份96通道特征
                             out_ch=decode_channels,        # 输出:1份96通道
                             num_heads=8,
                             window_size=window_size)
        
        # ===== 第五部分：加权融合 =====
        # 融合不同来源的特征
        self.WF1 = WF(in_channels=decode_channels, decode_channels=decode_channels)
        self.WF2 = WF(in_channels=decode_channels, decode_channels=decode_channels)
        
        # ===== 第六部分：分割头 =====
        # 最后的分类层：特征 → num_classes 个类别
        self.segmentation_head = nn.Sequential(
            ConvBNReLU(decode_channels, decode_channels),
            nn.Dropout2d(p=dropout, inplace=True),  # 随机丢弃部分特征，防过拟合
            Conv(decode_channels, num_classes, kernel_size=1)  # 转换为类别数
        )
        
        # 特征降维
        self.down = Conv(in_channels=3*decode_channels,
                        out_channels=decode_channels,
                        kernel_size=1)
```

### Forward 前向传播

```python
def forward(self, x, imagename=None):
    """
    完整的前向传播过程
    
    输入：
    - x: 图像张量 (B, 3, H, W)
      B: batch_size (通常2)
      3: RGB三通道
      H, W: 图像分辨率 (如512×512)
    
    输出：
    - 分割结果 (B, num_classes, H, W)
      每个像素有 num_classes 个分类概率
    """
    
    b = x.size()[0]           # batch_size
    h, w = x.size()[-2:]      # 原始分辨率
    
    # ===== 步骤1：骨干网络特征提取 =====
    # res1, res2, res3, res4 是四个不同尺度的特征
    # 尺度关系：
    #   res1: H/4 × W/4   (浅层特征，细节多)
    #   res2: H/8 × W/8
    #   res3: H/16 × W/16
    #   res4: H/32 × W/32 (深层特征，语义多)
    res1, res2, res3, res4 = self.backbone(x)
    res1h, res1w = res1.size()[-2:]
    
    # ===== 步骤2：特征通道统一 =====
    # 把 res2, res3, res4 的通道都转为 decode_channels（96）
    res2 = self.conv2(res2)  # 192 → 96
    res3 = self.conv3(res3)  # 384 → 96
    res4 = self.conv4(res4)  # 768 → 96
    
    # ===== 步骤3：多尺度特征上采样到相同分辨率 =====
    # 把所有特征都上采样到 res1 的分辨率
    res2 = F.interpolate(res2, size=(res1h, res1w), mode='bicubic', 
                        align_corners=False)
    res3 = F.interpolate(res3, size=(res1h, res1w), mode='bicubic', 
                        align_corners=False)
    res4 = F.interpolate(res4, size=(res1h, res1w), mode='bicubic', 
                        align_corners=False)
    
    # ===== 步骤4：拼接三个特征 =====
    # 沿通道维度拼接：[96, 96, 96] → 288 通道
    middleres = torch.cat([res2, res3, res4], dim=1)  # (B, 288, H/4, W/4)
    
    # ===== 步骤5：特征映射与小波变换 =====
    # FMS 会：
    # 1. 分解为局部(local)和全局(glb)特征
    # 2. 对局部特征做小波变换，获得高频(Fh)和低频(Fl)
    fusefeature_L, fusefeature_H, glb, local = self.fuseFeature(
        middleres, imagename
    )
    # 输出说明：
    # fusefeature_L: 低频特征
    # fusefeature_H: 高频特征
    # glb: 全局特征
    # local: 局部特征
    
    # ===== 步骤6：MDAF 多尺度对齐融合 =====
    # 分别作用到低频和高频特征上
    glb = self.MDAF_L(fusefeature_L, glb)      # 融合低频
    local = self.MDAF_H(fusefeature_H, local)  # 融合高频
    
    # ===== 步骤7：加权融合全局和局部特征 =====
    res = self.WF1(glb, local)  # WF 学习最优的融合比例
    
    # ===== 步骤8：与中间特征融合 =====
    middleres = self.down(middleres)  # 288 → 96
    res = F.interpolate(res, size=(res1h, res1w), mode='bicubic', 
                       align_corners=False)
    res = middleres + res  # 残差连接
    
    # ===== 步骤9：再次加权融合和浅层特征 =====
    res = self.WF2(res, res1)  # res1 是骨干网络的浅层特征
    
    # ===== 步骤10：分割头分类 =====
    # 96 通道 → num_classes (6类) 概率
    res = self.segmentation_head(res)  # (B, 6, H/4, W/4)
    
    # ===== 步骤11：上采样回原始分辨率 =====
    x = F.interpolate(res, size=(h, w), mode='bilinear', align_corners=False)
    # (B, 6, H, W)
    
    return x

"""
数据尺寸变化追踪：

输入: (2, 3, 512, 512)
  ↓ 骨干网络
res1: (2, 96, 128, 128)   # 512/4
res2: (2, 192, 64, 64)    # 512/8
res3: (2, 384, 32, 32)    # 512/16
res4: (2, 768, 16, 16)    # 512/32
  ↓ 通道转换
res2: (2, 96, 64, 64)  →  全部上采样到  (2, 96, 128, 128)
res3: (2, 96, 32, 32)  →                (2, 96, 128, 128)
res4: (2, 96, 16, 16)  →                (2, 96, 128, 128)
  ↓ 拼接
middleres: (2, 288, 128, 128)
  ↓ FMS 处理
输出: (2, 96, 128, 128) × 4  (多个特征)
  ↓ MDAF + WF 融合
处理特征: (2, 96, 128, 128)
  ↓ 分割头
分类: (2, 6, 128, 128)
  ↓ 上采样
最终输出: (2, 6, 512, 512) ✓
"""
```

## 2️⃣ 特征映射阶段 (FMS.py)

**作用**：
1. 组织多尺度特征
2. 执行小波变换
3. 生成局部和全局特征

**关键概念：小波变换**

小波变换的目的是把特征分解成不同频率成分：

```
原始特征 (256个数值)
    ↓
小波变换 (Wavelet Transform)
    ↓
  ┌── 低频分量 (64个数值)  ← 大尺度结构
  │
  └── 高频分量 (64个数值)  ← 细节纹理

现实类比：
- 低频 = 看图片的轮廓（建筑物的整体形状）
- 高频 = 看图片的细节（建筑物边界的锯齿状）
```

**代码流程** (伪代码)：
```python
class FMS(nn.Module):
    def forward(self, x):
        # x 是三个不同尺度特征的拼接
        
        # 1. 分离全局和局部特征
        x_global = self.extract_global(x)
        x_local = self.extract_local(x)
        
        # 2. 对局部特征做小波变换
        # 输入: (B, C, H, W)
        # ↓
        # forward: (B, C, H/2, W/2) - 低频
        # backward: (B, C, H/2, W/2) - 高频
        low_freq, high_freq = self.dwt(x_local)
        
        # 3. 返回分解后的特征
        return low_freq, high_freq, x_global, x_local
```

## 3️⃣ 多尺度对齐模块 (MDAF.py)

**作用**：融合空间域和频率域的特征

**核心思想**：
```
空间特征 (Fm)
    ↓
[多尺度卷积: 7×1, 11×1, 21×1]
  (不同尺度的感受野)
    ↓
与频率特征融合
    ↓
自适应权重学习
    ↓
融合结果
```

**代码理解**：
```python
class MDAF(nn.Module):
    def __init__(self, dim, num_heads, LayerNorm_type):
        super().__init__()
        
        # 创建多个不同大小的卷积核
        # 这些卷积核用来提取不同尺度的特征
        self.conv1_1_1 = nn.Conv2d(dim, dim, (1, 7), padding=(0, 3))
        self.conv1_1_2 = nn.Conv2d(dim, dim, (1, 11), padding=(0, 5))
        self.conv1_1_3 = nn.Conv2d(dim, dim, (1, 21), padding=(0, 10))
        
        # 竖向卷积 (高度方向)
        self.conv1_2_1 = nn.Conv2d(dim, dim, (7, 1), padding=(3, 0))
        self.conv1_2_2 = nn.Conv2d(dim, dim, (11, 1), padding=(5, 0))
        self.conv1_2_3 = nn.Conv2d(dim, dim, (21, 1), padding=(10, 0))
    
    def forward(self, x1, x2):
        """
        融合两个特征
        x1: 第一个特征 (如低频特征)
        x2: 第二个特征 (如全局特征)
        """
        
        # 多尺度特征提取
        # 【7×1卷积】在7像素宽度内提取信息
        attn_111 = self.conv1_1_1(x1)  # 局部联系
        # 【11×1卷积】在11像素宽度内提取信息
        attn_112 = self.conv1_1_2(x1)  # 中等尺度
        # 【21×1卷积】在21像素宽度内提取信息
        attn_113 = self.conv1_1_3(x1)  # 全局联系
        
        # 竖向也做同样处理
        attn_121 = self.conv1_2_1(x1)
        attn_122 = self.conv1_2_2(x1)
        attn_123 = self.conv1_2_3(x1)
        
        # 组合这些多尺度特征
        # 网络会学习如何权衡不同尺度的重要性
        fusion = attn_111 + attn_112 + attn_113 + \
                 attn_121 + attn_122 + attn_123
        
        return fusion
```

**数学表示**：
$$F_{fused} = \sum_{i=1}^{3} (Conv_{h_i}(x_1) + Conv_{w_i}(x_1)) + x_2$$

其中 $h_i$ 和 $w_i$ 是不同的卷积核大小 (7, 11, 21)。

## 4️⃣ 损失函数理解

### 交叉熵损失 (Cross Entropy Loss)

```python
# 假设有3个类别：建筑、道路、背景

# 模型预测（经过softmax）：
pred = [0.8, 0.1, 0.1]  # 预测是建筑的概率80%

# 真实标签（one-hot编码）：
label = [1, 0, 0]  # 确实是建筑类

# 交叉熵计算：
CE_loss = -[1*log(0.8) + 0*log(0.1) + 0*log(0.1)]
        = -log(0.8)
        ≈ 0.22

# 反向传播时：
# 梯度会推动 pred[0] 从 0.8 变高到更接近 1.0
# 让模型更确定这是建筑类
```

### Dice Loss

```python
# 对不均衡数据更友好
# 如果某个类别样本很少，CE_loss 会忽视它
# 但 Dice_loss 会重视所有类别

Dice = 2 * 交集 / (集合1 + 集合2)
     = 2 * TP / (2*TP + FP + FN)

# 范围 [0, 1]
# = 1: 完全分割正确
# = 0: 完全错误
```

## 5️⃣ 训练过程理解

### 训练循环伪代码

```python
for epoch in range(total_epochs):
    for batch_idx, (images, labels) in enumerate(train_loader):
        
        # 1️⃣ 前向传播：计算预测
        predictions = model(images)
        # predictions: (B, num_classes, H, W)
        # 每个像素有 num_classes 个概率
        
        # 2️⃣ 计算损失
        loss = loss_function(predictions, labels)
        # 比较预测和真实标签的差异
        
        # 3️⃣ 反向传播：计算梯度
        optimizer.zero_grad()   # 清空旧梯度
        loss.backward()         # 计算新梯度
        
        # 4️⃣ 参数更新：沿梯度方向调整权重
        optimizer.step()        # 更新模型参数
        
        # 损失会逐渐减小 ↘️
        
    # 验证
    val_loss = evaluate_on_val_set()
    
    # 如果验证损失好，保存模型
    if val_loss < best_loss:
        save_checkpoint(model)
```

### 监控指标

| 指标 | 含义 | 范围 | 好的值 |
|------|------|------|-------|
| **Loss** | 模型输出与标签的差异 | [0, ∞) | 越小越好 |
| **Accuracy** | 所有像素的正确率 | [0, 1] | > 0.9 |
| **mIoU** | 各类别IoU的平均值 | [0, 1] | > 0.8 |
| **IoU** | 交并比，单个类别的指标 | [0, 1] | > 0.7 |

**IoU 计算**：
```
IoU = 交集面积 / 并集面积
    = TP / (TP + FP + FN)

例子：
┌─────────────────────┐
│  预测为建筑(红色)  │
└──────┬──────────────┘
       │
┌──────┴─────────────┐
│ 实际是建筑(蓝色) │
└────────────────────┘

交集面积(紫色) = 完全正确的像素
并集面积(红+蓝) = 所有相关的像素

IoU = 紫色面积 / (红色+蓝色)面积
```

## 📊 完整流程总结

### 从数据到结果的完整流程

```
1️⃣ 数据加载
   磁盘 → 图像array(512×512×3) → 标准化 → batch打包
   
2️⃣ 骨干特征提取
   图像 → ConvNeXt → 4个多尺度特征
   
3️⃣ 特征统一
   4个特征 → 通道转换 → 上采样到相同分辨率 → 拼接
   
4️⃣ 特征分解
   拼接特征 → FMS → 多个特征分支
   其中一个分支 → 小波变换 → 高频&低频
   
5️⃣ 空频融合
   高频/低频 & 全局/局部 → MDAF → 融合特征
   
6️⃣ 加权融合
   融合特征 → WF(学习权重) → 最终特征
   
7️⃣ 分类
   特征 → 分割头 → num_classes 类别概率
   
8️⃣ 上采样
   (B, 6, 128, 128) → 上采样 → (B, 6, 512, 512)
   
9️⃣ 取最大值
   [0.8, 0.1, 0.1] → argmax → 0 (建筑类)
   
🔟 评估
   预测 vs 真实标签 → 计算 mIoU, Accuracy 等
```
