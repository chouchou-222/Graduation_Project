# SFFNet 论文复现 - 零基础学习指南

## 📚 项目总体理解

### 这是什么项目？
**SFFNet** 是一个用于**遥感图像分割**的深度学习模型。简单说就是：
- **输入**：卫星或无人机拍摄的航拍图像
- **输出**：给图像中的每个像素打上标签（如"建筑物"、"道路"、"树木"等）
- **用途**：识别卫星图像中的地物信息（urbanization监测、环境评估等）

### 核心创新点
论文提出的 SFFNet 有两个特别的地方：
1. **时空融合**：同时使用空间特征（图像直接的形状信息）和频率特征（通过小波变换提取的纹理信息）
2. **多尺度对齐**：使用特殊的 MDAF 模块对齐不同尺度的特征

## 🎯 数据理解

### 遥感图像的特点
- **RGB三通道**：就像普通照片一样的红绿蓝三个颜色通道
- **分辨率**：通常是 1024×1024 像素
- **标注**：每个像素都有一个类别标签（如类别0=背景，类别1=建筑，类别2=道路等）

## 🧠 深度学习基础概念速览

如果你是初学者，这些是要了解的最基本概念：

### 1. **神经网络** = 数学函数
- 输入图像 → [神经网络处理] → 输出分类结果
- 网络通过学习数据来调整内部参数（权重）

### 2. **卷积** = 图像特征提取工具
- 用一个小滑动窗口（卷积核）在图像上滑动
- 用来检测图像中的边界、纹理等特征

### 3. **池化** = 特征压缩工具
- 把大图像变成小图像
- 保留最重要的信息，加快处理速度

### 4. **上采样** = 分辨率恢复
- 把小图像放大回来
- 用于分割任务恢复到原始分辨率

### 5. **损失函数** = 学习目标
- 衡量模型输出与真实标签的差异
- 损失越小 = 模型越准确

## 🔄 SFFNet 网络流程（简化版）

```
           输入图像 (512×512×3)
                ↓
    ┌─────────────────────────────┐
    │  骨干网络 Backbone          │  提取初步特征
    │  (ConvNeXt或ResNet)         │
    │                             │  输出：多尺度特征
    └─────────────────────────────┘
           ↓           ↓           ↓
        x₁,x₂,x₃     x₄         (不同尺度)
           ↓
    ┌──────────────────────────┐
    │  特征映射阶段            │
    │  (Feature Mapping Stage)  │  处理空间特征
    └──────────────────────────┘
           ↓
    ┌──────────────────────────┐                    ┌──────────────────────┐
    │  全局特征                │    经过小波变换    │  高频/低频特征      │
    │  (spatial)               │ ─────────────────→ │  (frequency domain)  │
    └──────────────────────────┘                    └──────────────────────┘
           ↓                                                   ↓
    ┌──────────────────────────────────────────────────────────┐
    │  MDAF (多尺度对齐)                                       │  融合两个领域
    │  Multiscale Dual-representation Alignment Filter         │
    └──────────────────────────────────────────────────────────┘
           ↓
    ┌──────────────────────────┐
    │  解码阶段                │  上采样恢复分辨率
    │  (Decoder)               │
    └──────────────────────────┘
           ↓
        输出分割图 (512×512×类别数)
           ↓
        结果：每个像素被分配到一个类别
```

## 📊 各模块详解

### 1️⃣ 数据加载模块 (vaihingen_dataset.py)

**作用**：从硬盘读取图像和标签，准备成适合训练的批数据

**输入**：
- 图像路径和标签路径

**输出**：
- 单个样本：(图像, 标签)
- 批数据：通常是 batch_size=2 的数据批

**关键概念**：
- **数据增强**：随机旋转、翻转、颜色变换等，使模型更鲁棒
- **归一化**：将像素值从 [0,255] 变为 [0,1]

---

### 2️⃣ 骨干网络 (Backbone)

**作用**：初步特征提取（就像人类看图先形成初步印象）

**常用骨干**：ResNet, ConvNeXt 等

**输入**：图像 (B×3×H×W)
- B = batch_size（通常2-4）
- 3 = RGB三通道
- H×W = 图像分辨率（如 512×512）

**输出**：多尺度特征
```
x1: B × 64 × H/4 × W/4      (粗尺度1)
x2: B × 128 × H/8 × W/8     (粗尺度2)
x3: B × 256 × H/16 × W/16   (粗尺度3)
x4: B × 512 × H/32 × W/32   (最粗尺度)
```

**特性**：
- 越往后，分辨率越低，但特征"语义信息"越多
- 通道数(64,128,256...)决定了特征的"宽度"

---

### 3️⃣ 特征映射阶段 (FMS - Feature Mapping Stage)

**作用**：处理骨干网络输出的特征，准备用于频率分解

**输入**：骨干网络的多尺度特征 (x1,x2,x3,x4)

**处理流程**：
```
x1 ──→ [上采样] ──→ 恢复到x2的尺度
x2 ──────────────→ 不变
x3 ──→ [下采样] ──→ 压缩到x2的尺度
x4 ──→ [下采样] ──→ 压缩到x2的尺度
        ↓
    [融合成单一尺度特征]
        ↓
    输出标准化特征 Fm (shape: B×C×H/8×W/8)
```

**数学表示**：
$$F_m = f_{local}(x_1, x_2, x_3) + f_{global}(x_4)$$

---

### 4️⃣ 小波变换模块 (WTFD - Wavelet Transform Feature Decomposer)

**作用**：将特征分解为高频和低频两部分

**什么是小波变换？**
- 把一个信号/图像分解成不同频率的成分
- 低频：大尺度的结构（如主要的形状）
- 高频：细节（如边界、纹理）

**输入**：空间特征 Fm (B×C×H×W)

**输出**：
```
低频特征 Fl: B×C×H/2×W/2  (信息密集，可用于全局结构)
高频特征 Fh: B×C×H/2×W/2  (细节信息，用于边界检测)
```

**直观理解**：
- 一个 512×512 的图像经过小波变换后变成 256×256
- 分成 4 个象限，分别代表不同频率成分

---

### 5️⃣ MDAF 模块（核心创新）

**作用**：融合空间域和频率域的信息

**输入**：
- 空间特征 Fm
- 高频特征 Fh
- 低频特征 Fl

**处理原理**：
```
        空间特征 Fm              频率特征 (Fh, Fl)
           ↓                           ↓
    ┌─────────────────┐      ┌──────────────────┐
    │ 多尺度映射      │      │ 多尺度映射       │
    │ (7×1, 11×1等)  │      │ (7×1, 11×1等)   │
    └─────────────────┘      └──────────────────┘
           ↓                           ↓
    ┌──────────────────────────────────────┐
    │      动态融合（Adaptive Fusion）     │
    │  学习如何最优地组合这两类特征       │
    └──────────────────────────────────────┘
           ↓
    融合特征 F'
```

**关键创新**：
- 不是简单的相加，而是学习一个权重来自适应地融合
- 不同场景下的融合比例不同

---

### 6️⃣ 解码阶段 (Decoder)

**作用**：将特征逐步放大回原始分辨率，进行最终分类

**上采样过程**：
```
    融合特征 (H/8 × W/8)
           ↓ [上采样2倍]
      H/4 × W/4
           ↓ [上采样2倍]
      H/2 × W/2
           ↓ [上采样2倍]
      H × W (原始分辨率)
           ↓ [分类头]
    输出: 每个像素的类别概率
```

**输出**：(B × num_classes × H × W)
- 每个像素有 num_classes 个概率值
- 取最大概率的类别作为最终分类

---

### 7️⃣ 损失函数 (Loss Function)

**作用**：计算模型预测与真实标签的差异，指导网络优化

**思想**：真实标签给网络反馈 → 网络调整参数 → 下次预测更准

**常用损失**：
- **交叉熵 (Cross Entropy)**：分类的标准损失
- **Dice Loss**：对不均衡数据友好
- **联合损失 (Joint Loss)**：组合多个损失

**计算示意**：
```
预测结果: [0.8, 0.1, 0.1]  (三类概率)
真实标签: [1, 0, 0]         (第一类为真)
      ↓
交叉熵损失 = -log(0.8) ≈ 0.22
      ↓
反向传播：调整参数使预测概率更接近 1.0
```

---

### 8️⃣ 优化器和学习率调度

**优化器**：AdamW
- 用来调整网络参数
- 比简单的 SGD 更高效

**学习率调度**：CosineAnnealingWarmRestarts
- 开始时学习率小（ warm-up）
- 逐渐增大，再周期性重启
- 帮助模型跳出局部最优

## 📈 训练过程监控

### 输出指标解释

```
Epoch 10/105
Train Loss: 0.45
Val Loss: 0.52
Val mIoU: 0.72    ← 这是最重要的指标！
```

**mIoU (mean Intersection over Union)**：
- 衡量分割精度的标准指标
- 范围 [0, 1]，越接近1越好
- 公式：$mIoU = \frac{1}{N}\sum_{i=1}^{N}\frac{TP_i}{TP_i + FP_i + FN_i}$

其中：
- TP (True Positive)：正确分类的像素
- FP (False Positive)：错误分类为某类的像素
- FN (False Negative)：漏分的像素

### 常见错误及解决

| 错误 | 原因 | 解决 |
|------|------|------|
| CUDA out of memory | batch_size过大 | 减小 batch_size，改为2→1 |
| 模型不收敛 | 学习率太高 | 降低学习率 |
| NaN loss | 数据预处理问题 | 检查数据归一化 |
| 精度不提升 | 数据不足或质量差 | 增加数据增强 |

## ❓ 常见问题

**Q: 我没有GPU，能运行吗？**
A: 可以，但很慢。添加 `gpus=[]` 改为CPU模式，训练时间会长 50-100 倍。

**Q: 需要微调参数吗？**
A: 配置文件中的参数已经是论文里的最优参数，初学者建议直接用。

**Q: 分割结果不好，怎么办？**
A: 检查数据质量、增加训练轮数、或使用预训练权重。

**Q: 运行中断了，能继续吗？**
A: 可以！设置 `resume_ckpt_path` 指向上次的检查点。
